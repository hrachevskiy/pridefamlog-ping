pridefamlog-ping

Один файл расписания: раз в 5 минут трогает https://pridefamlog-worker.onrender.com/,
чтобы бесплатный Render не усыплял воркер семейных отчётов PRIDE, и раз в месяц делает
пустой коммит, потому что GitHub сам выключает расписания без свежих коммитов.

Секретов здесь нет: только публичный адрес воркера. Приватный репозиторий
`pridefamlog-worker` для таких частых запусков не подходит — там минуты Actions
платные (2000 в месяц), а этот работает бесплатно.
